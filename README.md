# 📝 Todo List

A simple Todo List web application built using **HTML**, **CSS**, and **Vanilla JavaScript**. This project allows users to add tasks dynamically and remove them from the list using JavaScript DOM manipulation.

## 🚀 Features

- ➕ Add new tasks
- 🗑️ Remove tasks
- ⚡ Dynamic task creation using JavaScript
- 🛑 Prevents page reload using `event.preventDefault()`

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## 📁 Project Structure

```
todo-list/
│── index.html
└── README.md
```

## ▶️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/todo-list.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.
